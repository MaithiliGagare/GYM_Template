# 🏋️ Gym Website Template

A modern and responsive **Gym Website Template** built using **HTML and CSS**. This project features a clean fitness-focused design with attractive sections and a user-friendly layout.

### ✨ Features

* 🏠 Modern Home/Hero Section
* 💪 About Gym Section
* 🏋️ Fitness & Training Programs
* 👥 Trainers Section
* 📋 Membership/Plans Section
* 📞 Contact Section
* 📱 Fully Responsive Design
* 🎨 Clean and modern UI

### 🛠️ Technologies Used

* **HTML5**
* **CSS3**

### 🎯 Purpose

This project was created to practice and demonstrate **HTML & CSS web development, responsive layouts, styling, and website design**.
